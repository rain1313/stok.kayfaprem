# KAYFA APP PREMIUM | Pricelist

Website pricelist modern untuk menampilkan daftar harga akun premium secara real-time menggunakan Google Sheets sebagai database.

## ✨ Features

- 📦 Data real-time dari Google Sheets
- ⚡ Menggunakan Google Apps Script API
- 🔍 Live Search
- 🏷️ Filter Status Produk
- 📊 Statistik Produk
- 📱 Responsive Design
- 🌙 Modern Dark UI
- 🚀 Deploy menggunakan GitHub Pages

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Sheets
- Google Apps Script
- GitHub Pages

- Varian
- Harga Reseller
- Harga Umum
